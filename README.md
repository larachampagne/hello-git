## Animation in README
### How it works
The whole animation is a link to an image. You change it by editing the URL.

- `https://readme-typing-svg.demolab.com/` is the base URL.
- `?` starts the list of settings.
- `&` separates each setting.
- `+` replaces spaces in your text, since URLs can’t contain spaces.
